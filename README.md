# BuildShare

> 让每一份创意，跨越世界共享

BuildShare 是一款轻量级的 Minecraft 建筑分享/蓝图交换模组。它帮助你轻松导出、分享并还原建筑作品，打破世界边界的限制。

## ✨ 功能特性

- **标记导出区域** – 使用导出标记方块框选建筑范围
- **一键导出建筑** – 挥动导出木棍，将导出方块选定的区域保存为结构文件
- **导入与还原** – 将结构文件放入导入方块，即可一键还原建筑
- **实时预览** – 导入前支持预览渲染，所见即所得
- **轻量便捷** – 无需复杂配置，即装即用

## 🎯 解决的问题

你是否曾为了一座精心打造的建筑，却只能孤芳自赏？  
BuildShare 让分享变得简单——你的作品不再被世界边界束缚，每一份创意都能被更多人看见。

## 📥 使用方法

1. 用 **导出标记方块** 框选需要分享的建筑区域
2. 手持 **导出木棍** 执行导出，得到结构文件
3. 将文件发送给好友
4. 好友将建筑文件放入 游戏文件夹\buildshare，预览确认后一键还原建筑
